Hey all — wanted to share a working prototype of a Bluesky embed widget! <br>

I'm Gaf and I built a lightweight, customizable feed viewer that works great inside Notion templates, websites, or dashboards. <br>

It shows the latest skeets from any public Bluesky user — with clickable @handles, #hashtags, URLs, and embedded media. It auto-refreshes every 60 seconds and works beautifully on mobile. <br>

💻 Live demo: https://gaf.nyc/bskyNotion2 <br>

🛠️ Built with @atproto/api, Vercel, and a little UI polish. <br>

Would love to help others embed this or hear feedback on what features you'd want next (threads? quote skeets? avatars?). <br>
